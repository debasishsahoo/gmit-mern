How a Website Works

1 User
User types URL and presses Enter
↓
2 Browser
Browser parses the URL and prepares to make a request
↓
3 DNS Resolution
Domain name is translated to IP address
↓
4 Internet
Request travels across the network to the server
↓
5 Web Server
Server receives the HTTP request
↓
6 Application
Application processes business logic and routes
↓
7 Database
Database is queried for requested data
↓
8 Response Generated
Server creates HTTP response with data (HTML/JSON)
↓
9 Browser Renders
Browser parses HTML, CSS, JS and renders the page
